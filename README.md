## Structure

```
index.html                       the whole site (HTML, CSS, JS)
Muhammad_AlAasar_CV_Final.pdf    CV download
Images/                          project screenshots (.png) and profile.jpeg
videos/                          project demo videos (.mp4)
Certificates/                    certificate images (.jpg)
```

File names are case-sensitive on GitHub Pages and must match the lists at the top of the `<script>` in `index.html`.

## Editing content

Projects, experience, skills and certificates are plain JavaScript arrays (`PROJECTS`, `JOBS`, `SKILLS`, `CERTS`) at the top of the script in `index.html`. Add an entry, commit, and the site updates.

## Run locally

Open `index.html` in a browser, or run `python -m http.server` in this folder and visit http://localhost:8000.
